# AI Manager Learning Lab

This repository is an **agent-agnostic lab environment** for a university Principles of Management assignment. It contains the common company case, a place for the student's Markdown management instructions, session logging, a Streamlit lab console, and academic PDF/ZIP exports.

**This project does not call an AI model and does not require an API key.** The student's own AI harness (Command Code, Claude Code, Cursor, ChatGPT, etc.) is the AI Manager. The lab provides the environment and the record.

Read `AGENTS.md` and follow it exactly. Use the student's instructions first, cite teacher-provided data, and log every turn.

Built-in skills in `builtin_skills/` are optional and invoked-only. Do not read or apply a skill body unless the student explicitly names the skill.
